# 电影磁力链接搜索工具 — 实现方案

## Context（背景与目标）

用户需要一个桌面工具：输入电影名称，跨国内外 BT 站点搜索可下载的磁力链接，对结果按质量评分排序，供手动复制到 qBittorrent 下载。

**已确认需求：**
- 搜索源：混合方案 — 内置直接爬取主流站点（YTS、1337x、The Pirate Bay、BT之家、电影天堂），同时支持配置本地 Jackett 作为增强聚合源
- GUI：PySide6（现代美观、表格交互好）
- qBittorrent 集成：仅显示磁力链接 + 手动复制（不做 Web API 推送）
- 评分维度：做种数(seeders) + 清晰度(分辨率) + 发布时间(新鲜度)，编码格式不参与评分
- 可打包为 exe，界面为中文

**已验证的技术事实（2026-09-21 实测）：**
- YTS API：`list_movies.json?query_term={title}` 返回 hash/seeds/peers/size/quality，单步，需拼装磁链
- The Pirate Bay：`apibay.org/q.php?q={q}&cat=200` 返回 JSON，含 info_hash/seeders/size/added(unix)，单步
- 1337x：Cloudflare 拦截，需 `curl_cffi` 模拟 TLS 指纹，搜索页→详情页两步取磁链
- BT之家：主域 `www.1lou.me`（Discuz），搜索→帖子页两步正则取磁链，无强反爬
- 电影天堂：主域 `dyttt.me`（Discuz 论坛），两步取磁链
- Jackett：本地 9117 端口 Torznab API，`indexerId=all` 聚合全部已配置源，字段最齐

## 关键组件设计

### 1. 数据模型 `core/models.py`

```python
class Resolution(str, Enum):
    FOUR_K = "4K"
    FHD = "1080p"
    HD = "720p"
    SD = "SD"
    UNKNOWN = "未知"

@dataclass
class TorrentResult:
    title: str
    magnet_link: str
    info_hash: str
    size_bytes: int
    size_display: str            # "1.5 GB"
    seeders: int
    leechers: int
    upload_date: Optional[datetime]
    source: str                  # "YTS" / "1337x" / "BT之家" / "Jackett" 等
    resolution: Resolution
    detail_url: str
    score: float = 0.0           # 评分阶段填充
```

### 2. 搜索源抽象 `sources/base.py`

```python
class SearchSource(ABC):
    name: str
    enabled: bool = True
    @abstractmethod
    def search(self, query: str) -> List[TorrentResult]: ...
```

每个源是同步实现（在 QThreadPool 工作线程中运行），用 `requests` 或 `curl_cffi` 发请求，返回 `List[TorrentResult]`。失败的源返回空列表并记录日志，不影响其他源。

**复用点：** `utils/magnet.py` 提供 `build_magnet(info_hash, title, trackers)` — YTS、Pirate Bay 共用同一套默认 tracker 列表拼装磁链。

### 3. 搜索编排 `core/search_manager.py`

- 继承 `QObject`，搜索时把每个启用的源包装成 `QRunnable`，提交到 `QThreadPool`（默认 5 并发）
- 每个源完成后通过 `Signal(list)` 发回结果，主线程聚合
- 全部源完成（或超时 30s）后：去重（按 info_hash）→ 评分 → 排序 → 发出最终结果信号
- 进度信号驱动状态栏更新（"YTS 完成(12) / 1337x 进行中..."）

**去重策略：** 同一 info_hash 出现在多源时，合并保留 seeders 最大值、来源标记为多源拼接（如 "YTS, Jackett"）。

### 4. 评分算法 `core/scorer.py`

三维度加权评分（默认权重 seeders 50% / resolution 30% / freshness 20%，可在设置中调）：

- **seeders_score（0-100）**：`100 * log(1+seeders) / log(1+max_seeders_in_batch)`，批次内相对归一化（电影热度差异大，绝对阈值不适用）
- **resolution_score**：4K=100 / 1080p=80 / 720p=60 / SD=40 / 未知=50
- **freshness_score（0-100）**：`max(0, 100 * 0.5^((today - upload_date).days / 180))`，半年半衰期指数衰减；无日期记 50
- **总分** = `0.5*seeds + 0.3*res + 0.2*fresh`，四舍五入到一位小数

排序：总分降序；同分按 seeders 降序。

### 5. HTTP 客户端 `core/http_client.py`

- 统一函数 `fetch(url, use_browser_tls=False)`：`use_browser_tls=True` 时用 `curl_cffi.requests`（1337x 专用），否则用 `requests.Session`
- 旋转真实浏览器 UA，可配置代理（http/https），超时 15s，最多重试 2 次（指数退避）
- 1337x 的 `curl_cffi` 用 `impersonate="chrome"` 绕过 Cloudflare TLS 指纹检测

### 6. 各源实现要点

| 源 | 类 | 步骤 | 关键技术 |
|---|---|---|---|
| YTS | `sources/yts.py` | 单步 | `list_movies.json?query_term=`，遍历 `movies[].torrents[]`，hash 拼磁链 |
| Pirate Bay | `sources/piratebay.py` | 单步 | `apibay.org/q.php?q=&cat=200`，info_hash 拼磁链，`added` 是 unix 秒 |
| 1337x | `sources/one337x.py` | 两步 | `curl_cffi` 绕 CF；搜索页解析 tr 行；详情页取 `magnet:?xt=...` |
| BT之家 | `sources/btbtt.py` | 两步 | `www.1lou.me` Discuz，`search.php?mod=forum&srchtxt=`；帖子页正则 `magnet\?xt=urn:btih:[A-Fa-f0-9]{40}` |
| 电影天堂 | `sources/dytt.py` | 两步 | `dyttt.me` Discuz，同上正则取磁链 |
| Jackett | `sources/jackett.py` | 单步 | `127.0.0.1:9117/.../torznab/api?t=movie&q=&cat=2000&apikey=&o=json`，可选源 |

### 7. UI 设计 `ui/`

**主窗口 `main_window.py`：**
- 顶部：`QLineEdit`（电影名）+ 搜索按钮 + 源筛选下拉（默认全选）+ 设置按钮
- 中部：结果表格 `results_table.py`，列：排名 / 标题 / 来源 / 分辨率 / 大小 / 做种 / 下载者 / 发布时间 / 评分 / 操作
- 底部：状态栏（搜索进度、结果数）
- 表格行右键菜单：复制磁力链接 / 复制 info_hash / 打开来源页面；双击行复制磁链并提示

**结果表格 `results_table.py`：**
- 用 `QTableView` + 自定义 `QAbstractTableModel`，支持点击表头排序
- 评分列用进度条/颜色直观显示（绿>70 黄>40 红）
- 标题列对长文本省略号 + tooltip 显示完整标题
- 顶部分辨率过滤复选框（4K/1080p/720p/全部）

**设置对话框 `settings_dialog.py`：**
- Jackett：URL + API Key + 启用开关
- 代理：http/socks 代理地址
- 源开关：每个源勾选启用
- 评分权重：三个滑块（seeders/resolution/freshness，自动归一化）
- 配置持久化到 `config.json`（放 exe 同目录）

### 8. 配置 `config.py`

`AppConfig` dataclass，`load()`/`save()` 读写 `config.json`（用户目录或 exe 同级）。字段：jackett 配置、proxy、各源 enabled、评分权重、窗口尺寸。

## 打包 exe

用 PyInstaller：
```
pyinstaller --noconfirm --windowed --onefile --name "电影磁力搜索" ^
  --collect-all PySide6 --collect-all curl_cffi ^
  --icon NONE main.py
```
- `--onedir` 比 `--onefile` 启动快但生成文件夹；首版用 `--onefile` 便于分发
- `curl_cffi` 需 `--collect-all` 收齐动态库
- 打包后测试在干净 Windows 环境运行

## 风险与备注

- **站点变更**：BT 站结构/domain 常变。各源独立成文件，便于单独修复；搜索失败时 UI 明确标注"XX源失败"
- **网络可达性**：国际站国内可能需代理，中文站国外可能需代理。代理在设置中可配
- **Cloudflare**：1337x 用 `curl_cffi` 绕 TLS 指纹；若仍失败则该源标记失败，不影响其他源
- **法律**：工具本身中立（类似搜索引擎），用户对下载内容自负其责；不在工具内做版权过滤
